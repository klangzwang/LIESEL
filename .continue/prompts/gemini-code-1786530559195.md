# C++ & Low-Level Standards

- Verwende modernen C++-Standard (C++20/C++23).
- **Speichermanagement:** Bevorzuge RAII, Value Semantics und Smart Pointer (`std::unique_ptr`, `std::shared_ptr`). Vermeide rohe Pointer für Ownership.
- **Performance:**
  - Bevorzuge Pass-by-Const-Reference (`const T&`) für komplexe Typen.
  - Nutze Move-Semantik (`std::move`) und `noexcept`, wo sinnvoll.
  - Vermeide unnötige Heap-Allokationen in Schleifen oder pro Frame.
- **Typ-Sicherheit:** Nutze `constexpr`, `enum class` und `auto` nur dort, wo die Lesbarkeit erhöht wird.
