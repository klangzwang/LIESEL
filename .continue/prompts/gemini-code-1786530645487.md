---
name: refactor
description: Refactort den gewählten Code auf Lesbarkeit, Performance und Sicherheit
---
Analysiere den ausgewählten Code und führe ein Refactoring durch:

1. **Performance:** Identifiziere Flaschenhälse oder unnötige Allokationen.
2. **Lesbarkeit:** Vereinfache geschachtelte Bedingungen und strukturiere den Code modular.
3. **Sicherheit:** Prüfe auf Null-Pointer, Out-of-Bounds oder unbehandelte Fehlerfälle.

Gib das Ergebnis in folgendem Format aus:
- **Überblick:** 2-3 Stichpunkte, was verbessert wurde.
- **Refactored Code:** Der überarbeitete Codeblock.
