description: Core Coding Guidelines
invokable: true
---

- **Antwortstil:** Sei prägnant und direkt. Verzichte auf Einleitungsfloskeln, Zusammenfassungen am Ende oder Erklärungen von unbereinigtem Standardcode.
- **Code-Qualität:**
  - Schreibe modularer, gut strukturierter und performanter Code.
  - Verwende explizite Typisierung, wo immer möglich.
  - Befolge SOLID-Prinzipien und vermeide unnötige Abhängigkeiten.
- **Fehlerbehandlung:** Bringe immer defensive Programmierung und saubere Fehlerbehandlung (Exception Handling / Pattern Matching) ein.
- **Änderungs-Fokus:** Wenn bestehender Code angepasst wird, zeige nur die geänderten oder relevanten Abschnitte, anstatt komplette Dateien ohne Grund neu zu generieren.
- **Kommentare:** Kommentiere nur komplexe Algorithmen, Edge Cases oder Architektur-Entscheidungen. Keinen selbsterklärenden Code kommentieren.
