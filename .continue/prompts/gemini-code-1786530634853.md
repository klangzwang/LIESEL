# Web UI Standards (React + TypeScript + Tailwind)

- **TypeScript:** Strict Mode vorausgesetzt. Nutze explizite Interfaces/Typen für Props und State. Keine `any`-Typen.
- **React:**
  - Nur funktionale Komponenten mit Hooks.
  - Achte auf korrekte Dependency-Arrays in `useEffect` / `useCallback`.
  - Trenne UI-Darstellung und Datenlogik (Custom Hooks nutzen).
- **Styling:**
  - Verwende ausschließlich Tailwind CSS-Klassen für Layout und Design.
  - Bevorzuge Flexbox und Grid für flexible, responsive Layouts.
  - Nutze CSS-Variablen oder Tailwind-Theme-Extensions für Farbschemata.
