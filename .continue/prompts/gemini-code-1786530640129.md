# Python 3.12+ Standards

- Verwende explizite Type Hints (`from typing import ...`) für alle Funktions-Signaturen.
- Nutze moderne Python-Features (z.B. Structural Pattern Matching, `dataclasses` oder `pydantic` für Datenstrukturen).
- Befolge PEP 8 Style Guides.
- Verwende `pathlib.Path` anstelle von String-Manipulationen für Dateipfade.
